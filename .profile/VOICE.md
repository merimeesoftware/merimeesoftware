# Public profile voice (GitHub + LinkedIn)

## Directional pull
- **Current title (honest):** DevOps engineer at Westfield
- **Direction (aspirational, not claimed title):** forward-deployed / agentic delivery
- **Proof hierarchy:** measured Westfield results → Elyra → client delivery → earlier career
- **Surfaces:** GitHub (proof) + LinkedIn (full story). No separate portfolio site.

## Tone
- Short, high-signal, first person
- Evidence over hype; never invent titles (not “Forward Deployed Engineer” yet)
- Prefer outcomes people can picture over lab-report metrics (keep p95/n= on LinkedIn or PORTFOLIO-PUBLIC, soften on GitHub)
- No badge soup, emoji walls, or “Hi I’m …” fluff
- Comfortable naming teaching / marketing / client work as *why* FDE fits — one or two lines, not a resume dump

## Language patterns to prefer
- “Building toward…” / “deliberate about…”
- “Other teams depend on” / “blast radius”
- “Safe to point at real systems”
- “Discovery → prototype → production”
- “AI accelerates; engineer owns”

## Language patterns to avoid
- “Passionate about…” / “guru” / “ninja”
- Claiming FDE as current title
- Internal system names, colleague names, proprietary topology
- Dead client links or redesigned sites that no longer represent the work
- X/Twitter unless explicitly re-enabled

## Skills vs Stack
- **Skills** = capabilities and how you work (especially AI/agents)
- **Stack** = tools you’ve actually run in production or serious projects
- Skills lead; Stack stays one compact line
